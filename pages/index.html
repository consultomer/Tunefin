Tunefin

Search, play and keep YouTube Music in Jellyfin and Finamp.

Jellyfin plugin repository
manifest.json

Install

  1. In Jellyfin, open Dashboard → Plugins → Repositories and click +.
  2. Name it Tunefin and paste the repository URL above.
  3. Open Catalog, choose Tunefin and click Install.
  4. Restart Jellyfin.
  5. In Dashboard → Plugins → Tunefin, set the Sidecar URL and the YouTube folder, then click Test connection.
  6. Each user connects their YouTube account at https://<your-jellyfin>/YouTube.

Requirements

Jellyfin 12.4. Tunefin also needs its small companion service, ytm-sidecar, which runs yt-dlp and ffmpeg. Set it up with Docker, or directly on the server:

  • Jellyfin in Docker
  • Jellyfin without containers

Tunefin is not affiliated with YouTube, Google or Jellyfin. It uses yt-dlp and unofficial YouTube APIs, which can break at any time.
