Tunefin

Streams YouTube Music through the ytm-sidecar service and downloads favorited songs into your music library.

Address of ytm-sidecar as seen from the Jellyfin server, e.g. http://ytm-sidecar:8787 in Docker Compose.
Must match the sidecar's API_KEY environment variable, if you set one.
Song searches get the top YouTube matches added after your local results, labelled "· YouTube".
Also raise MAX_CONCURRENT_DOWNLOADS on the ytm-sidecar container to at least this number.
Optional. Each line is pinned as a folder in the YouTube Music channel. Searches you type in the search box also appear there as recent folders.

Users & liked songs

Same host folder the sidecar mounts as YOUTUBE_DIR (e.g. /media/YouTube). Each user gets a private library in a sub-folder. Must not be inside another library.

Each user has a private library, Liked – name, that only they can see. Songs liked by several users are stored once (hardlinks). Users connect their YouTube Music account themselves at /YouTubeMusic/Account (they must be signed in to Jellyfin Web in the same browser).
